# 智械 AI 场景动画 Skill

根据科普文案设计原创场景，用 AI 视频模型制作有实际动作的短镜头，再通过后期剪辑完成视频。包含风格库、分镜表、画面设定卡和单镜测试记录。

默认制作 9:16 竖屏视频，不生成配音和底部逐字口播字幕；人物、机器人不是必需的。实际使用时可以根据项目要求更改。

## 使用

将本目录作为 `zhixie-scenic-video` Skill 安装到支持 `SKILL.md` 的智能体工具中，或在对话中指定读取 [SKILL.md](SKILL.md)。提供文案、希望参考的画面，以及可选的最终配音文件，例如：

> 用智械场景动画 Skill，根据这段文案设计视频。先做一个短镜头，确认风格后再继续。

先读取 Skill，再按任务需要读取 `references/` 下的风格库与模板。已有配音时按实际音频对齐；未提供配音时只能预估时长。

## 能力边界

本 Skill 是制作规则，不包含视频生成模型，也不保证一键出片或复现特定作品。需要另行确认可用模型、额度、费用、输入方式及上传内容；生成后需实际播放检查动作和画面，再剪辑成片。
