# 画面设定卡（复制后填写）

为一条视频维护一份简短的统一设定。只固定本片需要跨镜一致的细节；允许不同景别、空间和动作有变化，不要把全部视频都锁成一个模板。

- 视频主题 / 主旨：
- 风格方向及参考依据：
- 本片原创视觉隐喻（与文案的关系）：
- 场景及空间结构：
- 核心物件（形状、大小、颜色、材质、位置关系）：
- 角色或动物（有需要才填写：外观、服装、比例、可辨识特征）：
- 色彩与材质：
- 光线 / 时间 / 氛围：
- 构图与前、中、后景：
- 动作风格（力度、速度、惯性、变化前后）：
- 镜头语言（景别变化、运动方式、节奏）：
- 跨镜保持的锚点（最多列 3–5 条）：
- 哪些元素可以变化：
- 画面中要避免的内容（畸形、错字、固定品牌标识等按需填写）：
- 授权可用的参考图及来源：

## 使用

制作单镜提示词时，带上与该镜相关的锚点、动作和运镜；无需把无关设定塞满每条提示词。参考图可辅助统一，但不保证跨镜一致，生成后需播放对照。参考他人作品仅提炼色彩、材质、构图和节奏等方法，另行设计原创主体与画面，不臆称参考作者的制作过程。AI 生成概念画面不能当作真实产品演示、事件记录或亲测画面。
