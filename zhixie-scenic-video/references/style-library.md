# 智械场景动画：风格参考库

这些是原创制作方向，不是经过成片验证的预设，也不保证复现参考作者的画面。先根据文案和用户反馈选一种方向；没有确定偏好时，给出 2–3 个简短方向供挑选。参考片用于观察构图、材质、动作与镜头语言，不照搬具体场景、人物或标志。

每个镜头都要有能解释文案的**主体动作和变化结果**。人物、机器人不是必需的；不固定使用米色、统一的卡片、标题、账号名和编号。下面的 5 秒镜头只是示例，实际生成时根据内容与模型调整。

## 方向 A：电影感微缩世界

- **适合**：AI 帮人办事、决策链路、权限边界等抽象概念；用户偏好的温暖、有空间纵深的场景可从这个方向开始。
- **空间和材质**：可触摸的微缩工作台、书架、工具室或街景；混合纸、木、磨砂塑料与金属，比例统一。不要把“温暖”写成必须泛黄的米色滤镜。
- **光色**：依话题选择深蓝、苔绿、陶土红等底色，暖光或冷光承担明确叙事功能；保留暗部与自然阴影。
- **主体动作与镜头**：可见物件实际发生动作，摄影机缓慢跟随或沿桌面移动；动作前后状态清楚。每镜一般只安排一个主要动作，避免同时旋转、变形和大幅穿梭。
- **5 秒示例**：微缩工作台上，一枚小推车载着文件匣经过两道分拣口；到付款闸门前，闸门落下，推车停住，镜头侧向跟随后停稳。画面表达“能做事，但支付前要确认”。
- **避坑**：不要只有静态场景与推拉镜头；不要让所有场景都变成玩具屋，也不要强加可爱人物、拟人机器人或固定颜色。

## 方向 B：手工纸雕与定格拼贴

- **适合**：解释流程、层级、模型输入输出；需要轻盈、清晰且有手作感的内容。
- **空间和材质**：分层纸板、剪纸边缘、局部网点与真实投影；前后层形成纵深，按主题改变空间布局。
- **光色**：清爽的蓝绿、橘红、紫灰等有控制的配色；纸张可白、彩色或深色，避免默认旧报纸或复古米色。
- **主体动作与镜头**：纸片折叠、滑入、穿过纸门或推动纸制机构，呈现逐格手作的轻微节奏；镜头沿纸层侧移或从局部切到全景。
- **5 秒示例**：三层纸制抽屉依次滑开，纸文件沿槽道向前移动，遇到一个折起的纸门后停止；门后的空间暂不开放。
- **避坑**：不用一堆文字卡片冒充场景；不要把轻微抖动当成唯一动作，避免拼贴过密影响可读性。

## 方向 C：写实物件的视觉隐喻

- **适合**：权限、隐私、风险、成本等需要简洁而有情绪的科普话题。
- **空间和材质**：现代真实尺度的桌面、走廊、玻璃隔间或档案室；玻璃、钢、织物、纸张质感清楚，场景保持克制。
- **光色**：可用冷蓝与暖琥珀、黑白加单一警示色等组合；对比服务于信息，不把科技感等同于霓虹。
- **主体动作与镜头**：通过钥匙转动、抽屉开启、信封被挡住等具体动作表达概念；近景捕捉动作，再切到中景交代空间。
- **5 秒示例**：透明抽屉里的信封沿传送带前进，接近玻璃门时门上出现柔和的红色灯光，信封停下；镜头由近景稍稍后移，看到门两侧的空间。
- **避坑**：隐喻必须能被口播上下文解释，不制造不存在的真实产品或事件画面；不靠闪烁警告、代码雨和大量 UI 装饰堆科技感。

## 方向 D：图形化立体信息空间

- **适合**：对比多个概念、解释步骤和数据流；希望更明快但仍然有真实空间运动的内容。
- **空间和材质**：简洁的立体几何平台、轨道、半透明容器或展台，使用哑光材料和清晰轮廓；空间不是平面信息卡。
- **光色**：深紫搭青绿、奶白搭钴蓝与珊瑚色、黑灰搭酸橙绿等，按主题选定主色与强调色；控制颜色数量。
- **主体动作与镜头**：球体或实体模块沿轨道分流、组合、被闸门拦截；镜头跟随主物件转向或从遮挡物后切入。数据大小仅作示意，不能伪造真实比例。
- **5 秒示例**：三个不同形状的模块沿轨道汇合，只有经过授权标记的模块穿过门，另一模块被挡住；摄影机从侧上方移动至正面，最终定格在状态差异上。
- **避坑**：不要让镜头运动代替主体动作；避免所有场景都变成漂浮图标、箭头和大字。

## 方向 E：手绘二维动画

- **适合**：AI 产品如何影响日常生活、个人 Agent 的行动过程；适合轻松、有情绪的叙事。
- **空间和材质**：有透视的二维街道、书房或办公室；线条有轻微粗细变化，色块简洁，保留少量手绘纹理。
- **光色**：钴蓝配橘、草绿配紫或黑白加一色；根据主题选择，留足主体与背景的对比。
- **主体动作与镜头**：纸张折叠、抽屉打开、工具互相传递；主体动作有准备、变化和停顿，镜头平行跟随或在景别间切换。
- **5 秒示例**：一张桌面待办纸折成纸飞机，飞过书桌，在一本打开的手册旁轻轻落下，带出“AI 查阅手册后做事”。
- **避坑**：不要把单张插画平移称为逐帧手绘动画；避免过度复杂的肢体动作，也不模仿具体动画作品的角色或造型。

## 方向 F：透明剖面机械

- **适合**：解释工作流程、工具调用、反馈循环和系统分工。
- **空间和材质**：透明亚克力或玻璃装置，内部能看见少量杠杆、拨片和腔体；材质和接触点清楚，留出观察空间。
- **光色**：冷白、石墨灰或深海蓝为背景，选一种对比色标出正在工作的物件。
- **主体动作与镜头**：一个物件推动拨片，带动可见机构产生结果；镜头由外部缓慢靠近或侧移观察内部，单镜保持因果清楚。
- **5 秒示例**：一个无字输入块进入透明装置，轻推一片拨杆；另一端的文件匣随之打开，展现“输入触发工具”。
- **避坑**：明确是比喻，不当作真实模型内部结构或系统架构；不要塞入大量机械零件，避免因穿模失去因果。

## 方向 G：液体与粒子实验

- **适合**：讲数据筛选、聚合、噪声和质量差异；适用于需要微观视觉的知识点。
- **空间和材质**：玻璃容器、滤网、液体与少量颗粒，微距景深和真实光影；实验台不必出现人员。
- **光色**：可用墨蓝与青绿、透明白与朱红或黑色与金色，保证液体和容器边缘可辨。
- **主体动作与镜头**：液滴汇聚、流动或被滤网分离；镜头微距跟随或由焦点转换揭示结果。
- **5 秒示例**：两滴不同颜色的液体流入透明漏斗，颗粒留在滤网上方，液体进入下方容器，表达“筛选”。
- **避坑**：物理实验只是视觉比喻，不声称真实训练过程或准确比例；避免仅靠流光和粒子漂浮堆氛围。

## 方向 H：黏土逐格动画

- **适合**：模型试错、协作、任务拆解和轻松友好的抽象概念。
- **空间和材质**：可见手工压痕的彩色黏土、纸板布景或布面桌台，物体比例和质感保持统一。
- **光色**：柔和的侧光与清晰投影；可选明快蓝绿、暖橘紫或低饱和灰粉，不固定为糖果色。
- **主体动作与镜头**：物体挤压、回弹、拆分或组合，保留逐格动作的轻微节奏；摄影机小幅侧移或保持固定。
- **5 秒示例**：一个黏土文件夹挤压变形，分成两个小文件夹，分别落入不同位置，表现“把任务拆成两步”。
- **避坑**：不强行出现真人手或角色；变形要能看懂前后关系，别让所有物体无缘由地蠕动。

## 方向 I：像素世界与游戏关卡

- **适合**：权限边界、操作步骤、规则与路径选择。
- **空间和材质**：低分辨率像素房间、网格地面或简洁地图；使用有限色板和清晰像素轮廓，避免引用现有游戏 IP。
- **光色**：可使用暗蓝加亮黄、紫绿或黑白双色等组合，主体与背景有明确对比。
- **主体动作与镜头**：物件按格移动、碰撞或改变状态，镜头可进行水平卷轴跟随；动画动作真实发生，像素边缘保持清晰。
- **5 秒示例**：像素文件夹在网格房间内移动，经过一个工具图标后变成已整理的文件，再停在存档格中。
- **避坑**：不要依赖密集小字、复杂界面或具体游戏角色；放大静图不能冒充动态像素动画。

## 方向 J：版画剪影与光影剧场

- **适合**：讨论信息偏差、算法影响、风险和需要留白的观点。
- **空间和材质**：木刻般的纹理、剪影层次、镂空图案和舞台投影；以明暗关系形成可辨的主体与空间。
- **光色**：黑白、深靛配珊瑚或墨绿配暖白；控制套色数量，保留纹理细节。
- **主体动作与镜头**：剪影遮挡、透光图案移动或影子逐渐改变；镜头由局部扩展到全景，揭示新的视觉关系。
- **5 秒示例**：一束光穿过带孔的纸板，只照亮桌上物件的一部分；纸板缓慢移开，更多物件显现，表达“观察范围有限”。
- **避坑**：隐喻需结合文案解释，不能把画面演绎当成真实事件；避免只有烟雾和抽象光斑而没有可读动作。

## 选择与组合

| 想要的观感 | 可先试的方向 | 重点区别 |
| --- | --- | --- |
| 有空间、有故事 | A 电影感微缩、E 手绘二维 | A 有实体和电影光影；E 像动画片，线条与逐帧动作明显。 |
| 有手工触感 | B 纸雕拼贴、H 黏土逐格 | B 依靠纸层折叠和拼接；H 依靠软体挤压、变形和回弹。 |
| 清楚解释机制 | F 透明机械、D 立体信息空间 | F 侧重可见的机械因果；D 侧重几何模块的关系与变化。 |
| 更有视觉冲击或思考感 | G 液体实验、I 像素关卡、J 剪影剧场 | G 是微观流动，I 有网格和游戏节奏，J 用光影与留白表达观点。 |
| 克制、现实感 | C 写实物件隐喻 | 使用真实尺度的空间与物件，通过具体动作解释抽象概念。 |

风格是起点而不是固定套餐：根据文案先选空间和视觉材质，再选主体动作与镜头，不要每种风格都重复“轨道—闸门—停止”。一条视频可以在用户认可后混用，但应通过色彩、光线或持续出现的核心物件维持整体感；不应为了多样强行切换。

## 使用方式

1. 判断主题想让观众理解什么，选择一个主风格；用户希望多样时，可以更换空间与景别，保持颜色、光线和材质锚点一致。
2. 在分镜中写清主体、环境、动作起点、动作过程、结果、镜头运动和时长；根据实际工具组织提示词，文字交给后期叠加。
3. 先测试一个关键镜头，实际播放后记录运动、主体稳定性与构图问题；无法调用视频模型时只交付设定和分镜，不把示意图称为动态样片。
4. 生成图像或动画只是解释性视觉演绎；涉及真实事件、产品和界面时，核对事实和素材来源。
