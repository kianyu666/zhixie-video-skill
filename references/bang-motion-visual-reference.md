# 视觉风格与连续镜头

制作前从内容、受众与用户参考确定风格，不继承上条视频的配色或版式。方向不明确时，给出少量差异明显的候选；可先做短动态验证，避免只凭静态图判定视频效果。用户已指定风格或要求直接制作时，直接执行并依据反馈迭代。

## 可选方向

- 连续动作：同一对象跨越不同空间，镜头跟随、推近细节、转向下一对象再拉远。适合流程、任务与因果。
- 视觉新闻：深色或高对比环境，真实且可使用的照片、来源标注与动态批注。适合行业事件；示意图不得冒充实拍。
- 编辑图解：冷白、浅灰或其他合适背景，以照片或插画、细线、动态图表组织复杂信息；不把所有信息都塞进同一种卡片。
- 卡通拼贴：物件、纸片、笔迹和纹理分层运动，配色随主题重新设计；不固定米色、吉祥物或真人。
- 影像与动态图形结合：将可用且有授权的真实画面置入不同景别和遮罩，镜头的运动与叙事动作相配合。

这些是方向，不是现成模板或质量保证。按需要混合，但一条视频应保持视觉逻辑统一；画面不要固定出现智械、AGENT 或编号作为顶栏。

## 连续镜头实现

先为整段规划空间：明确持续出现的主体、空间中的信息节点、每个节点发生的动作和镜头路径。用大于视口的共享画布，或以等效方式实现镜头位置、缩放和前后景；例如主体从对话、查找、操作移动到授权关口，镜头跟随具体动作并适时切换远近景。每个关键动作包含可理解的前后变化和阅读停顿。Remotion、GSAP 或其他工具均可实现；不把换工具本身当成果。

做动态预览并检查：主体是否跨节点保持连续，移动是否有目的，元素是否真的分层、逐项发生变化，是否有遮挡、过快或出框。只对多张独立卡片淡入淡出、整张插画慢慢缩放，或只更换背景颜色，不应称为连续镜头或多风格。
