# 智械视频 Skill

用于制作不真人出镜的竖屏 AI 知识科普、行业解读和观点视频。根据脚本设计画面、生成素材、制作分镜动画并检查成片。

## 画面方向与默认交付

- 漫画分镜与报刊拼贴：暖白纸面、黑色墨线和网点，以蓝色及少量橙色点缀。
- 人物和机器人按内容需要选择；素材、卡片、标题、描线和转场分层运动。
- 默认 9:16、1080×1920、30fps；默认不加配音和底部口播字幕，必要的标题和解释文字可保留。

## 使用

把仓库内容安装到支持 `SKILL.md` 的智能体环境，例如放入 `skills/zhixie-video/`，然后说“用智械 Skill 做一个关于……的视频”并提供选题或文案。

Skill 提供制作规范，不是独立的视频生成程序。生成图片、制作动画和导出视频需要当前环境具备相应工具，由智能体根据内容制作并检查。仓库不包含样片、视频工程或第三方素材；不同环境的实际效果与可用能力需要另行验证。
