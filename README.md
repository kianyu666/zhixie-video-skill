# 智械视频 Skill

用于制作不真人出镜的竖屏 AI 知识科普、行业解读和观点视频。根据脚本设计画面、制作分镜动画并检查成片。

## 画面与默认交付

- 漫画分镜与报刊拼贴：暖白纸面、黑色墨线和网点，以蓝色及少量橙色点缀。
- 按内容设计主体、动作与结果，人物和机器人按需使用。
- 默认 9:16、1080×1920、30fps；默认不加配音和底部口播字幕，必要的标题和解释文字可保留。

## 使用

将仓库安装到支持 `SKILL.md` 的智能体环境，例如 `skills/zhixie-video/`，然后说“用智械 Skill 做一个关于……的视频”并提供选题或文案。

[漫画动画组件和验证工程](assets/comic-kit/README.md) 包含手册抽出、选择展开、步骤执行、圈线与转场，需准备对应的 Node.js、Remotion 依赖和浏览器。它是可修改的素材与示例，每个新话题仍需设计分镜和检查成片，不是输入文案即可一键出片的软件。

仓库不包含验证视频成片；不同电脑的依赖和渲染仍需实际验证。
