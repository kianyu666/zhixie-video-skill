# 智械视频 Skill

面向“智械／智械编年史”的竖屏 AI 行业知识科普与资讯视频制作技能。从资料核实、口语稿和分镜，到画面、配音、字幕与成片检查，按当前环境的实际能力推进。

知识科普优先尝试用户认可的手绘线稿和动态图解方向。人物可选，不需要真人出镜；选题和视觉表现不限定为某一个样片。

## 使用

将本仓库作为 `zhixie-video` Skill 安装到支持 `SKILL.md` 的智能体环境，或把仓库内容放入该环境的 `skills/zhixie-video/` 目录。之后提出“用智械 Skill 做一个关于……的视频”即可。具体配音、图像生成和视频渲染能力取决于实际环境，使用前需分别检查。

已获认可的 5 秒手绘动效仅用于确定视觉方向；完整视频的自动化制作和发布仍需在目标环境中实际验证。本仓库不包含该测试视频或第三方素材。
